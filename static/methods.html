The Making of the Record

Every album has a back cover. Here is ours, the data, the idea, the tools, and where the machines helped.

Official national birth-registration name counts across the Anglosphere: USA, England & Wales, Scotland, Northern Ireland, Ireland, Canada, Australia and New Zealand, for every year from 1997 to 2023.

We chose 1997–2023 because it is the window where all eight countries publish comparable yearly data. Names below each country's privacy threshold aren't published, so ultra-rare spellings may be undercounted.

🎼Why We Wrote It — the idea

Everyone has a story about their name — where it came from, whether it was common or rare, how it felt to grow up with it. That everyday intimacy is exactly what pulled us toward this.

Baby names sit at a rare crossing point: deeply personal, yet recorded as clean public data across eight countries and nearly three decades. We used them to ask a simple question with a surprisingly rich answer — when does a name belong to the whole world, and when does it belong to just one place?

🎛️The Studio — how it was built

Data wrangled and the countryness metric computed in Python (pandas). The story is a set of standalone HTML / CSS / JavaScript sheets, stitched into one scroll and served through Streamlit (Community Cloud).

Python · pandas HTML / CSS / JS Streamlit SVG charts Web Speech · audio

Every chart is hand-built SVG or lightweight canvas, no chart library, so each visual matches the music theme exactly.

🤖The Session Musicians — AI usage

Generative AI was a collaborator, not the author. It helped with:

🎨 The two composer illustrations (Aria & Cormac) and the singing-baby cover art.
💬 Copy-editing and phrasing the narration.
🛠️ Drafting and debugging HTML/CSS/JS for the interactive sheets.
🔊 Pronunciation clips for the name quizzes.

All data, metrics and findings are our own, computed from the source records and verified by hand. No numbers were generated by AI.
